## 1. 글자·기호 사이 간격 (`0x1008b480`, 표 `0x100bf318`)

```
글자 노드 폭 = 글리프 폭 + 간격
간격 = MulDiv(s, T[이 노드 분류][다음 노드 분류], 100) × 7      ; 다음 노드가 없으면(줄 끝) 0
```
- **간격은 글자 뒤(오른쪽)에 붙고**, 이 글자와 **다음** 노드의 분류로 정함. 앞쪽 간격은 앞 글자가 붙여 줌.
- **분수·근호·괄호·첨자 같은 상자 노드는 자기 뒤에 이 간격을 붙이지 않음**(첨자 노드는 예외, 1-3). 그래서 `분수 =` 는 0, `= 분수` 는 231.
- `{ }` 묶음은 간격에 투명: 묶음 안 마지막 글자는 묶음 다음 노드를 "다음"으로 봄(`k{geq}0` 양쪽 다 231).

### 1-3. 첨자 노드 뒤 간격 (`0x1008e270`)
- 첨자 묶음(위·아래첨자) 노드는 분류 1로 보고 **자기 뒤에** `MulDiv(s, T[1][다음], 100) × **10**` (×7 아님, s = 본체 크기).
  예 `x^2 + 1` 에서 첨자 뒤 이항 = 22×10 = 220 HU(18.3px), `x^2 =` 는 330 HU(27.5px).
- 간격이 0 이고 위첨자가 있고 본체가 대문자 A–Z 글자면 대신 `MulDiv(s,15,100)` 을 폭에 더함(이탤릭 보정, 위첨자 x 도 +15%·s).

### 1-4. 첨자 안 간격
- 첨자 안 글자는 첨자 크기 s₁ = MulDiv(s,68,100) = **748** 로 같은 식: 이항 MulDiv(748,2,100)×7 = **105 HU(8.75px)**, 관계 154(12.8px), 쉼표 49.
  2단 첨자 s₂ = MulDiv(748,68,100) = 509 → 이항 70 HU.
- 확인용 `a _{`n+1}` = 2253 이 이 값으로 정확히 맞음. 실측 15px 는 `+` 글리프 E048 의 좌우 여백(advance 795/1024, 10ppem 에서 8px=600 HU 상자)이 낀 잉크 사이 거리로 보임 — 같은 자리를 잉크가 아닌 글리프 원점으로 다시 재 보기 바람.

### 1-5. 공백·사분각
- `~` = 글꼴 폭 = **s/2** (550). `` ` `` = (s/2)/4 버림 = **137**. 둘 다 분류 1 → 앞 글자 간격은 T[앞][1](이항 뒤 154, 관계 뒤 231)로 그대로 남고, 자기 뒤에도 T[1][다음]이 붙음(`~` 다음이 `=` 이면 +231).

## 2. 위·아래첨자 (`0x1008e270` 배치, `0x1008dfd0` 그리기)

y 는 아래가 +, 0 = 본체 칸 가운데(글자 칸 높이 1125 의 가운데).
```
첨자 크기     s₁ = MulDiv(s, 68, 100)                 ; 1100→748, 2단 509, 3단 346
기준 상자     본체 글자 칸: top = −562, bottom = +563  (본체 없으면 ∓ s₁/2 쪽 값)
f            = 마지막으로 잰 첨자 글꼴 높이 (보통 s₁ = 748)  ← s 가 아님
아래첨자 중심 = bottom − MulDiv(f, 20, 100)           ; 563 − 150 = +413
위첨자 중심   = top    + MulDiv(f, 25, 100)           ; −562 + 187 = −375
제한          아래첨자 위끝은 0(가운데)보다 위로 못 감, 위첨자 아래끝은 0 보다 아래로 못 감
폭           = max(위폭, 아래폭) + (1-3 간격 또는 대문자 보정)
아래·위첨자 x = 본체 바로 뒤(위첨자만 대문자 본체면 +15%·s)
```
- 검증: `x ^{3}` 높이 = 750(첨자 위끝 −750) ~ 563 → **1313** ✓, `x _{0}` = −562 ~ 413+375=788 → **1350** ✓ (결과.hwpx h).
- PDF 기준선 차이(글꼴 ascent 0.80 기준): 위첨자 올림 338−(−375+225) = **488 HU = 40.7px** ✓, 아래첨자 내림 (413+225)−338 = **300 HU = 25.0px** ✓.
- 겹 첨자: 같은 식을 첨자 안에서 다시 적용(크기 68% 씩, f 도 그 크기). `x_a^b` 는 한 노드에 위·아래 둘 다(위는 [0x7c], 아래는 [0x78]).
- 왼쪽 첨자(LSUB/LSUP)는 다음 노드를 본체로 씀.

## 3. cases · pile · matrix

### matrix · cases (`0x10094050` 배치, `0x10093d10` 그리기)
```
칸 크기 = 각 칸을 s 로 잼
열 폭   = 그 열 칸 폭의 최대,  열 사이 = MulDiv(s, 20, 100)   ; 220
줄 높이 = 그 줄 칸 높이의 최대, 줄 사이 = MulDiv(s, 15, 100)   ; 165
전체    W = Σ열폭 + 열사이 + 왼괄호폭 + 오른괄호폭,  H = Σ줄높이 + 줄사이,  세로 가운데 = 축(0)
칸 세로 = 줄 안에서 가운데 ((줄높이 − 칸높이)/2)
칸 가로 = cases: 왼쪽 / matrix 류: 가운데
괄호    = cases 왼쪽 { (E079 폭 525, 오른쪽 없음), pmatrix ( , bmatrix [ , dmatrix | ; 크기는 H 로 늘임(3차 4절)
```
- 검증: `matrix{0 & d # 9 & e}` = 525+220+525 = **1270**, H = 1125·2+165 = **2415** ✓ (263/308 일치, 나머지는 `rm`).
- 한 줄 글자만이면 줄 기준선 사이 = 1125+165 = **1290 HU (1.173·s)**.

## 4. 적분 · 합 · lim

### 적분 int/dint/tint/oint/odint/otint (`0x1008c580`, `0x1008c350`)
```
글리프   int E05B(그릴 때 E072), dint E073, tint E074, oint E075 …, 크기 = 200%·s (2200)
gW, gH  = 그 크기 글리프 폭·칸 높이 (11pt: 1350, 2175)
아래끝   x = gW − MulDiv(s,50,100)      ; 1350−550 = 800 (글리프 안쪽으로 들어감)
         y(중심) = +gH/2                 ; +1087
위끝     x = gW + MulDiv(s,5,100)       ; 1405
         y(중심) = MulDiv(s,68,100)/6 − gH/2   ; 124 − 1087 = −963
본문 x   = gW + max(아래폭 − 50%·s, 위폭 + 5%·s) + MulDiv(s,1,100)
폭       = 본문 x + 본문폭 ;  끝값 크기 68%. 빈 끝값은 높이 0
```
- 검증 8/8: `int` 1416, `int _{-2}` 1891, `int _{n-1}` 2446, `int _{0} ^{2}` 1791 … 모두 ✓. 높이 `int` 2050, `int _{p}` 2425, `int _{0} ^{2}` 2800 ✓.

### 합·곱 sum/prod/coprod/inter/union (`0x1008cd10`, `0x1008cab0`)
- 글리프 E067(sum)·E068(prod)·E069·E06A·E06B, 크기 **180%·s**. 세로 몫 = 글리프 높이 × 75%.
- 끝값 크기 68%. 아래끝은 글리프 몫 아래(위끝 = +몫/2), 위끝은 위(아래끝 = −몫/2), **둘 다 가로 가운데**. 글리프 y = −몫/2 − 10%·몫.
- 폭 = max(글리프폭, 위폭, 아래폭) (디컴파일 일부 깨짐 → 추정). job 에 단순 sum 예가 없어 **실측 대조 안 됨**.

### lim / Lim (`0x1008ed50`, `0x1008eaa0`)
- "lim" 단어 폭 = GDI 로 l·i·m 각각 잰 합(로만), 높이 = 그 글꼴 칸(11pt 에서 1350).
- 아래끝(68%)은 단어 바로 밑(위끝 = 단어 칸 아래끝), 단어와 아래끝 모두 그 열에서 가운데.
- 폭 = max(단어폭, 아래끝폭) + 본문폭. 검증: `lim` h 1350, `lim _{x`->`0}` h 1350+750 = **2100** ✓, 폭 1875 ✓.
