## ① rm 글자·함수 이름

- rm 글자는 **PUA 코드로 저장**되고, 그릴 때·잴 때 문맥 플래그(ctx+0x850=0)이면 ASCII 로 바꿈(`0x10084930`, `0x10084f60`): 소문자 PUA E0E5–E0FE → `a`–`z`, 대문자 E000–E019 → `A`–`Z`. 폭 = gw(ASCII 코드, s)(HYhwpEQ 안의 ASCII 글리프, 같은 96dpi 규칙).
- **기준선이 올라감**: 소문자 y −= MulDiv(fh, 67, 1000), 대문자 y −= MulDiv(fh, 65, 1000) (11pt: −74, −72 HU = 약 6px). 기계어 0x10084a29·0x10084ae2 에서 직접 읽음. 실측 `sin x`·`rm A` 0 px.
- 함수 이름(sin cos tan log ln exp det max min …)은 rm 글자 연속과 같음. 분류 1 → **앞뒤 간격 0**(`sin x` = 525+300+600+600 = 2025 ✓).
- rm/it 범위: 현재 `{ }` 묶음 끝까지, `&`·`#` 칸 경계를 넘어 유지(matrix 실측), `it` 로 되돌림.
- 위첨자 대문자 보정 +MulDiv(s,15,100) 은 **rm 대문자에도** 적용(`rm K ^{h}` 1365 ✓).
- 확실도: 코드 + 실측. 남은 것: 키워드 붙은 토큰 쪼개기(`rmP`=rm+P 로 보이나 일부 실패), 함수이름 목록 전체.

## ② LEFT/RIGHT 늘인 괄호 (`0x10091e50` 크기, `0x10091bf0` 그리기, 괄호 객체 `0x100a1500`·`0x100a13d0`·`0x100a16a0`·`0x100a1830`)

```
W     = 왼괄호폭 + 내용폭 + 오른괄호폭           ; 안쪽 여백 0. 상자 top/bottom = 내용 그대로
괄호폭 = gw(가운데 조각, s);  < > 와 임의 글자는 max(폭, h/4),  < > 폭은 ×2/3
h     = 내용 높이,  y = 내용 위끝,  x = 왼쪽 / 왼쪽+왼폭+내용폭
```
| 문자 | 위·아래·가운데(·이음) | 한 글자 | 문턱(이상이면 조각) |
|---|---|---|---|
| ( ) | E07C·E07E·E07D / E07F·E081·E080 | E044 / E045 | 3·cell(s) |
| { } | E078·E07A·E079·이음 E07B / E082·E084·E083·E07B | E04B / E04C | 3·cell(s) |
| [ ] | E100·E103·E101 / E102·E104·E105 | E049 / E04A | 2·cell(s) |
| \| | — | E101 | cell(s) |
| < > | — | U+2329 / U+232A | cell(s) |

- **한 글자**(h < 문턱): 글꼴 높이 = h, 폭 = s/2 로 늘여 y = 내용 위끝(TA_TOP). `[ ]` 는 x + s/8, `< >` 는 x − s/8.
- **( )** 조각: 위 y, 아래 y + h − c (c = cell(s)), 가운데 조각은 글꼴 높이 N = (MulDiv(c,5,100)·2 + (h − 2c)) / 0.098 를 50000 씩 끊어 y + c − MulDiv(c,5,100) + k·4900 에.
- **{ }**: k = (h − 3c)/2, i7 = k·0.26/0.48, e = MulDiv(s,5,100); 위 y, 가운데 y + k + c, 아래 y + 2k + 2c, 이음 두 개(글꼴 높이 2e + k/0.48) y + c − i7 − e, y + 2c + k − i7 − e.
- **[ ]**: 위 y, 아래 y + c + (h − 2c), 가운데 E101/E105 글꼴 높이 MulDiv(c,5,100)+MulDiv(c,80,100)+(h−2c) 를 y + c − MulDiv(c,80,100) 에.
- 확실도: 코드 + 실측(pmatrix 3줄 조각 6개 0 px, 한 글자 괄호 0 px). 0.098·0.26·0.48 은 float 상수(0x100bfdd0·dd8·de0).

## ④ matrix · pmatrix · bmatrix · dmatrix · cases · pile (`0x10094050`·`0x10093d10`, `0x10095760`·`0x10095450`)

## ⑤ int · sum · lim (`0x1008c580`/`0x1008c350`, `0x1008cd10`/`0x1008cab0`, `0x1008ed50`/`0x1008eaa0`)

- **int**: 글리프 크기 S2 = MulDiv(s,200,100), gW = gw(code,S2), gH = cell(S2). 글리프 위끝 = 축 − gH/2(TA_TOP 아님, 기준선형). 아래끝 x = gW − MulDiv(s,50,100), 축 +gH/2; 위끝 x = gW + MulDiv(s,5,100), 축 MulDiv(s,68,100)/6 − gH/2; 본문 x = max(아래x+아래폭, 위x+위폭) + MulDiv(s,1,100). **빈 끝값은 그 축 위의 높이 0 상자**(그래서 `int` 단독 h 2050). 바로 뒤가 `{…}` 이면 그 묶음이 int 의 본문(뒤 간격 없음, `int {x}=0` ✓). 그릴 코드 E05B→E072 는 rm 문맥일 때만.
- **sum·prod**: S2 = MulDiv(s,180,100), G = MulDiv(cell(S2),75,100). W = max(gW, 아래폭, 위폭), 글리프 x = W/2 − gW/2, 위끝 y = 축 − G/2 − MulDiv(G,10,100). 아래끝 위끝 = 축 + G/2, 위끝 아래끝 = 축 − G/2, 둘 다 가운데. 본문을 품지 않음.
- **lim**: 단어 크기 S2 = MulDiv(s,120,100), L = cell(S2). 단어 폭(잴 때) = l·i·m 각각 gw(S2) 합. 단어 x = (W/2) − 단어폭/2, y 위끝 = 축 − L/2. **단어는 문자열 한 번(`0x10084cf0`)으로 그려서 둘째·셋째 글자는 장치(600dpi) ppem 으로 진행**(1px 차 해결). 아래끝(68%) 위끝 = 축 + L/2, 가운데. `{…}` 본문은 x = 왼쪽 + W.
- 확실도: 코드 + 실측(int 73.9%, sum 63.1%, lim 68.1% 식 전체).
